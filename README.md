# 那个谁

**九月，我们还不认识。**

一款以大学生活为背景的实时探索游戏。你以留白的主角走进校园，在日程之间安排自己的去处，通过相遇和选择，逐渐认识那些最初面容模糊的人。

当前版本实现了**九月一日至五日的完整军训篇**：入学领衣、站军姿、拉歌、领队选拔与结营，穿插四位人物的十二段个人经历。中文名已确定为「那个谁」，英文名待定；`roll` 是仓库和 npm 包的内部名称。

**[在线试玩](http://139.224.30.109:8000/)** · 2026-09-13 已核验线上 9 个公开文件与本地提交 `eb6d132` 的构建产物逐项 SHA-256 一致，HTTP 状态、MIME 与缓存响应正确。此前核验确认该版本已在线，当时没有重新上传。

**本轮工作区新增的近景演出、动作热点与音乐增强尚未发布。** 在线试玩目前仍对应上面的 `eb6d132`，体验本轮改动请使用本地开发入口。

## 开始游玩

需要 Node.js 22 或更新版本。

```bash
npm ci --omit=optional
npm run dev
```

打开 [本地游戏](http://127.0.0.1:3000/)。端口被占用时运行：

```bash
npm run dev -- --port 3001
```

无需账号，进度保存在当前浏览器。首次从九月一日 15:20、宿舍附近开始；之后可以从扉页继续存档，或确认后开始新的一局。浏览器清理网站数据后，本地进度也会删除；当前没有跨设备同步。

## 怎样体验这一章

- **自由探索**：校园包含宿舍、操场、食堂、图书馆公共区、树荫和校门。点击或轻触地面行走，点击人物和地点可走近互动；也可用 WASD 或方向键移动。建筑和池塘会影响路线。
- **留意时间**：标准速度为现实 1 秒对应校园 2 分钟，可在设置中改为 2 倍或 4 倍。对话、菜单、节拍练习、扉页和页面隐藏期间暂停；关闭游戏后不补算离线时间。
- **按自己的节奏安排去处**：查看日程、选择目的地，或使用「等一会儿」推进不超过三十分钟。19:00 后可回宿舍休息至次日 07:00；22:00 停时等待休息。
- **走进相遇的近景**：靠近人物后进入对应地点的近景，用逐镜文字、人物动作和道具细节展开交流。可点画面热点看看帽扣、小票或水壶纸条，也可逐镜继续、直接回应或回看这段对话。观察不会替你选择分支，也不会额外增加关系。
- **慢慢认识人物**：歪帽檐同学、抱书的同学、室友和教官各有自己的日程。个人故事需要在不同日期、地点和时段继续；重复点击不会增加关系。姓名随介绍显示，面容随具体经历逐步清晰。
- **留下自己的选择**：主动表现、安静陪伴、尊重边界和表达分歧都有回应。了解程度与亲近程度分开，已经认识的面容不会因分歧重新模糊。
- **听见校园的声音**：原创背景乐以轻钢琴与拨弦陪伴探索，随白天、晚间和近景调整。音乐与脚步、纸页、餐盘等音效分别开关；音乐音量可单独调节。训练节拍期间背景乐让出声音空间，页面隐藏后停止发声。
- **完整结束**：迟到、错过集合和未报名都能继续。自荐领队会进入可跳过的八拍练习，没有成绩门槛。结营后回宿舍，或到第五日 22:00，可查看本局回忆并导出文本。

探索时按 `E` 或空格与附近对象交流；近景中按空格或回车继续下一镜，选项出现后可用数字 `1—4` 选择，`Esc` 结束交谈或打开／关闭暂停菜单。拖动地图可平移，鼠标滚轮或画面缩放按钮可调整视野。移动端使用轻触、拖动和屏幕按钮。设置中的「安静的画面」可减少动态，逐镜阅读与直接回应仍可使用。

这段校园生活也希望让两个年龄阶段的人都能进入：十七至十九岁的玩家可以体验刚入学时的陌生与试探，毕业多年的人可以从衣架碰响、食堂找座、挂断电话后的停顿里认出熟悉的日常。主角保留代入空间，亲近可以来自同学、室友、朋友和师生之间的一次具体回应。

## 当前工程

运行时使用浏览器原生 ES 模块、Canvas 2D、CSS、Web Audio 和 localStorage。没有前端框架或 Ink 运行时依赖；`ssh2` 仅用于手动部署。

```text
index.html                  页面入口
src/main.mjs                界面、输入、主循环、近景推进与浏览器存档
src/world.mjs               校园绘制、坐标投影、碰撞与寻路
src/simulation.mjs          日期、日程、事件、关系与存档状态恢复
src/content.mjs             人物、校历、个人剧情与选择内容
src/scene-content.mjs       逐句近景分镜、动作、道具与演员归属
src/cinematic.mjs           近景环境、可动人物、面部清晰与热点坐标
src/audio.mjs               原创乐谱、场景配器、道具音效与音频调度
src/encounter.css           近景字幕、动作热点、阅读控制与响应式样式
src/styles.css              页面、对话、肖像清晰阶段与响应式样式
public/art/                 封面、人物肖像与六地点近景背景图集
scripts/dev.mjs              本地开发服务器
scripts/build.mjs            静态构建
scripts/deploy-remote.mjs    SSH 手动部署
tests/                      模拟、地图、近景、音乐与开发服务器测试
```

旧 `css/`、`js/`、`ink/`、`stories/` 及相关构建脚本已移除。`POC/`、`assets/` 和原设计文档保留为历史参考，当前运行入口不加载它们。旧版的 Ink、对齐工具、固定三场景和结尾一次性揭面说明不适用于新版。

## 检查与构建

```bash
npm test
npm run build
```

测试覆盖日程与人物路线、选择与读档、练习结果、可行走路径、近景分镜与动作归属、热点和减少动态、原创乐谱与音频调度，以及静态资源服务。自动化检查不替代实际画面与听感检查；验证进展由交接文档记录。构建输出为 `dist/`，只包含 `index.html`、`src/` 和 `public/` 中公开资源的副本。模块保持原生导入路径，服务器应允许资源重新验证缓存。

本地开发服务器只监听 `127.0.0.1`。服务器测试会短暂监听本机随机端口；受限执行环境需要允许本机网络。最新验证结果及验证边界见 [HANDOFF.md](HANDOFF.md)。

## 部署与文档

部署继续沿用现有 Nginx、SSH 和 GitHub Actions。手动执行 `npm run deploy:remote` 会重新构建并上传完整 `dist/`；CI 在推送 `main` 或手动触发后先测试、构建，再发布相同目录。账号、密钥和站点路径仍由既有环境变量／Secrets 配置。操作说明见 [DEPLOY.md](DEPLOY.md)。已核验的线上版本为 `eb6d132`；本轮近景和声音增强仍在本地工作区，尚未执行发布。后续更新前需恢复可用的本机部署认证，不影响当前站点访问。

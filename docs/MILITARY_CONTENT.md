# 《那个谁》军训篇：已实现内容与规则

2026-09-13。以本轮用户确认的重做方向为准：主角留白、校园自由探索、按比例推进的游戏时间、逐渐认识人物、章末只回看本局实际发生的经历。本文记录 `src/content.mjs` 与 `src/simulation.mjs` 的实际行为，不是待实现清单。

## 这一章怎样展开

军训篇压缩为九月一日至五日，便于用一段完整体验验证校园生活机制。第一天 15:20 入场，玩家已经抵达宿舍附近；从第二天起，每次休息后在 07:00 开始新的一天。每日 22:00 校园时间停止，等待玩家回宿舍；第五日 22:00 会自然进入回忆，避免因缺席或漏掉某个人而无法结局。

校园由宿舍、图书馆一楼公共阅览区、食堂、操场、树荫、校门组成。五个校历事件是：

- 九月一日 16:00—17:30，在校门领取军训服。错过后可在宿舍领取备用套装。
- 九月二日 09:00—11:30，在操场站军姿。留意歪帽檐同学的不适，可以报告、先询问意愿，或让开空间观察；教官会及时照看对方，所有选择都有合理后续。
- 九月三日 16:00—18:00，在操场拉歌。可以起头、接上同学轻轻的拍子，或者认真听完再鼓掌。
- 九月四日 09:00—11:00，在操场进行领队选拔与练习。可以自荐、询问室友是否愿意尝试并协助，或者留在后排帮助看齐。
- 九月五日 16:30—18:30，在操场结营。可以帮忙收拾、走进散场的人群，或在原地多待一会儿。之后仍可自由活动和道别。

时间到达时，事件入口自动开放，相关人物会按安排聚到活动地点。到场超过二十分钟会出现迟到的归队叙事。做出事件选择后先阅读回应，关闭回应页才推进到活动结束时刻；阅读期间不会消耗时间；普通个人对话关闭时也不额外扣除任何分钟。校历集合期间点击参与集合的人物，会优先进入当前活动，活动结束后才恢复个人剧情，避免日常开场覆盖主线。取消尚未选择的对话不会替玩家作决定，事件窗口仍在时可以再来。

缺席不会阻断后续日期。事件结束会收到错过通知，下一次安排照常开放。结营缺席也保留回宿舍查看回忆的路径。游戏不把沉默、没有报名或错过某次活动等同于人格缺陷。

## 四个人怎样变得具体

每人有三段独立个人经历，共十二段个人剧情、三十六个带独立回应和具体回忆的选项。另有五段校历剧情、十四个选项。个人剧情从初次留意、相识到理解，至少分布在三个游戏日；不能通过在同一地点重复点击一次性刷完。

**歪帽檐同学 → 李屿**

初见在操场或树荫，先记住总扶帽檐的动作和不合身的训练服。下一天再在树荫相遇，才知道名字、以前练一千五百米，以及忘记吃早饭却不愿停下来的习惯。再隔一天的 17:30—19:00，在操场遇见李屿，会听见“大家都是因为我跑得快才记住我”的顾虑，以及想看看摄影社的念头。选择可以是没有计时地走一圈、劝李屿不必一直证明，或者承认不完全懂但愿意听。

参加站军姿会留下不同前情；后面的相遇会记得玩家是报告、先询问意愿，还是观察。约好吃早饭后，再遇见时李屿会主动说起今天确实吃过了。

**抱书的同学 → 陈可**

初见在图书馆，先看到用食堂小票做的书签，或一张标着树荫的私人校园地图。下一天再来，知道名字，也听见来图书馆有时只是因为这里不用急着与人熟悉。再隔一天的 19:00—20:30，在树荫里，陈可会分享藏在笔记本后的歌词和舞台草图。可以邀请陈可唱一点、给未来的排练室在地图上留一颗星，或者尊重暂时只让一个人知道的愿望。

拉歌时若选择跟上轻轻的拍子，晚间相遇会记得这件事。这个人物并不止于“学霸”；阅读和音乐是同一个人的两个部分。

**新室友 → 周舟**

初见在宿舍，先经历认错床号、放下行李这样的小事。下一天在食堂遇见，知道周舟的名字，也听懂主动做攻略、帮人占座背后的用力。再隔一天的 19:00 以后回宿舍，会碰见周舟挂断给家里的电话：电话里说得很热闹，真实的大学生活却还有不习惯。可以一起聊普通的小事、约着慢慢走一段路，或安静陪坐。

领队选拔里，推荐室友的选项先征求室友意愿，再共同练习，不把对方强行推上台。

**教官 → 王教官**

初见在操场或树荫，先听见哨声之外关于休息、迟到或搬水的交谈。下一天在树荫里，知道王教官的姓氏和水壶手写纸条的来处。至少隔一天且到第四日以后，再在树荫相遇，听王教官说起自己也曾是队列里跟不上的人，因而常走到后排看看。

可以认同，也可以坦白说口令仍让人害怕。后者会让信任下降一点，但认识程度照常加深：面容的清晰表示了解，不能等同于讨好。

## 清晰程度、姓名和亲近程度

内部状态用 `clarity: 0..3` 表示陌生、留意、相识和理解。每完成一段新的个人经历提高一阶段；校历事件只会让相关人物达到“留意”，不会跳过个人相遇直接看清整个人。姓名只在故事实际介绍后显示；王教官初始也只显示“教官”。玩家始终留白，不生成预设姓名、性别、身世或最终面孔。

`trust` 记录亲近与回应，可以增加、保持或下降。熟悉后的日常问候会更主动；对王教官提出语气意见后，再见时也能听出回应。已经认识的面容不会因为分歧重新变模糊。具体视觉细节由显示层使用 `clarity` 驱动，游戏文案不要求显示数值等级条。

每段经历有唯一 ID，记忆和关系变化最多登记一次。再次遇见已经聊过的人会得到日常回应；相遇时间或地点不对，也只会自然打招呼。换场、读档和重复点击不会制造新的亲近程度。

## 人物日程

日程使用 07:00、09:00、11:30、13:30、15:30、17:30、19:00、20:30 为边界，分为八段。校历事件进行时优先覆盖日常路线。

- 李屿：清晨操场，上午操场，午间树荫，午休宿舍，下午树荫，傍晚操场，晚饭食堂，之后宿舍。
- 陈可：早饭食堂，上午图书馆，午饭食堂，午后图书馆，傍晚食堂，19:00 到树荫，20:30 回宿舍。
- 周舟：清晨宿舍，上午校门，午饭食堂，午后宿舍，再到食堂；19:00 回宿舍。
- 王教官：上午操场，午间与午后树荫，下午操场，17:30 树荫，19:00 操场，20:30 校门。

初日作少量迎新调整：15:20 室友在宿舍，李屿在操场试帽子，陈可在图书馆。领取服装时只有室友前往校门；正式训练和结营则四人都到操场。

主动等待一次最多推进三十分钟，并会停在更近的日程边界、活动前提醒或活动开始／结束时刻。玩家可明确知道刚过去多久，不会一次略过整个可相遇时段。19:00 以后在宿舍附近可以睡到次日 07:00。结营之后回宿舍可以提前合上这一章。

## 回忆与存档

回忆逐项记录实际选择：经历 ID、日期、时间、标题、人物以及对应分支的具体文字。不推测玩家多年后的命运，不揭示没发生的秘密。完全没有留下故事记忆的游玩路径，会保留一段“你走过的校园”，同时保持所有人物陌生。

自动存档由界面层调用控制器，逻辑层提供 JSON 字符串和容错恢复。存档包含日期时间、位置、日程状态、关系、已选分支的记忆、剧情标记以及当前对话。关闭游戏时不记录需要补偿的挂钟时间，恢复时不会计算离线进度。

选择前读档会恢复同一选择页。选择后、回应页尚未读完时读档，会恢复回应和剩余的事件用时，不再发放第二次关系进度。损坏的 JSON、新版本存档或不合法结构会回退／清理；没有有效对话的“进行中”事件会恢复为可进入状态或按时间结算缺席。

## 显示层接口

`createGame(saved)` 接收 JSON 字符串、对象或空值，返回稳定的 `state` 引用及以下方法：

- `advance(minutes)`：正向推进校园分钟；对话、结局期间拒绝推进。
- `setPlayer(x, y)`：更新 0—100 世界内的位置，自动记下今天经过的地点；对话期间拒绝移动。
- `getNPCs()`：当前人物坐标、地点和活动。
- `getSchedule()`：今天的校历安排及 `upcoming / available / active / complete / missed` 状态。未来日期可由 `EVENTS` 静态数据呈现。
- `getAvailableInteractions()`：当前人物、环境和活动入口，包含距离。`fresh` 表示该人物目前有新个人剧情。
- `interact(id)`：在交互半径内进入对话。ID 分别为 `npc:li`、`event:standing`、`object:dorm` 形式。
- `choose(index)`：作出一次选择，停留在回应页；再次选“继续”才关闭。
- `dismissDialogue()`：取消尚未决定的对话；回应阶段则完成已经选择的行动。
- `waitUntilNext()`：等待不超过三十分钟或到更近的时刻边界。
- `sleep()`：晚间在宿舍附近进入次日；结营后进入回忆。
- `recordPractice({ hits, total, skipped })`：在领队自荐的回应阶段接收轻节奏练习结果。结果只记一次，保留命中数、总拍数与是否跳过三个标量；跳过强制记零次命中，不伪造成绩，也不影响通过或人物理解。
- `getMemories()`：返回本局记忆的副本。
- `serialize()`：返回可直接写入 localStorage 的 JSON 字符串。

## 已验证内容

`node --test tests/simulation.test.mjs` 当前包含 27 项测试，覆盖日历开闭、迟到、错过补领、NPC 日程、距离限制、阅读暂停、取消选择、重复事件、跨日认识、信任与清晰分离、完整四人人物路线、选择前后存档、损坏存档、主动等待、休息、22:00 停时、全部缺席仍能结局，以及只产生实际经历回忆。补充覆盖集合人物优先进入当前活动、节奏练习重复上报、分数差异、跳过不伪造命中、读档保留练习标量和错误阶段拒绝提交。

领队自荐接入八拍轻节奏练习。命中五拍以上、有几步没踩准和主动跳过各有独立反馈，另留下一段具体练习回忆；没有强制成绩门槛，不改变是否完成活动，也不按准确度增加羁绊。显示层负责节拍和操作，逻辑层只校验结果提交的阶段、保存事实和生成对应回应。


## 完整验证路线

这条路线用于确认所有人物阶段与主线都可在同一局发生，正常游玩无需照着完成。

1. 第一天，依次在宿舍见室友、图书馆见陈可、操场或 15:30 后的树荫见李屿、操场见教官。16:00—17:30 到校门领衣。19:00 后回宿舍休息。
2. 第二天，09:00 参加站军姿。11:30 结束后在树荫与李屿、教官相识，再去食堂认识周舟。13:30 后到图书馆认识陈可。晚间休息。
3. 第三天，16:00 拉歌。18:00 结束后先去跑道找李屿，19:00 前触发没有计时的这一圈；19:00 到树荫听陈可讲音乐，再回宿舍和周舟谈一谈。
4. 第四天，09:00 领队自荐并完成或跳过八拍练习。11:30 到树荫与教官谈最后一排的脚步。晚间休息。
5. 第五天，16:30 结营，18:30 散场后回宿舍合上这一章。所有人都可以达到理解，十七段剧情记忆加上一段实际练习记忆，总计十八段。

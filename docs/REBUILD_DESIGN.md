更新日期：2026-09-13。**设计已对齐，用户已明确授权实现；当前已完成军训篇代码，正在进行最终整合验收。** 本文记录确认后的产品方向、实际首版范围，以及重做前全部文档的审阅结论。

## 1. 已确认的产品方向

中文名为「那个谁」，英文名待定。`roll` 继续作为内部工程名称。主角留白，玩家自由代入大学当期的学生身份；没有人物匹配问卷、预设姓名／性别／身世，也不在结尾揭示一张固定的主角面孔。

游戏核心是：**在随时间运转的校园里决定去处，通过相遇与选择，逐渐把身边的“那个谁”认识为一个具体的人。**

探索采用 2D 斜俯视校园，点击或方向键移动；交谈使用人物近景。游戏内时间按比例推进，离线、对话和菜单不走时。日历、地点、时段和既有经历共同触发故事：未来可延伸至考试、社团和学期生活，但第一次完整交付明确只做军训篇。

已确认保留真实、细碎、带轻微幽默的校园体验，以及选择后的即时回应和被下一次相遇记住的行动。认识程度与亲近程度分开，人物在过程中逐步清晰；不采用旧稿“始终无五官、结算才一次揭面”的规则。

## 2. 已实现的章节范围

首章压缩为九月一日至五日。玩家第一天 15:20 从宿舍附近入场，之后每天从 07:00 开始，经历自由活动与校历安排交织的五天。

- 九月一日 16:00—17:30：校门领取军训服，错过可回宿舍补领。
- 九月二日 09:00—11:30：操场站军姿，留意身边同学的状态。
- 九月三日 16:00—18:00：操场拉歌，可以起头、接上拍子或认真听完。
- 九月四日 09:00—11:00：领队选拔，自荐、征求室友意愿后协助、留在后排都可推进。
- 九月五日 16:30—18:30：结营集合；散场后仍留出自由活动和道别时间。

地图是连通的校园外部空间，包含宿舍、图书馆一楼公共阅览区、食堂、操场、树荫和校门。四位 NPC 各有三段独立个人经历，共十二段；加上五段校历剧情，形成首章的完整内容。具体人物路线和条件见 [军训篇内容与规则](MILITARY_CONTENT.md)，该文含剧情细节。

到达活动时间会自动出现通知、活动入口及集合人物。玩家需自己走近参加；超过开始后二十分钟进入迟到版本，结束后记作缺席。校历集合期间，同场人物优先进入活动，避免日常开场覆盖主线。取消尚未选择的对话不产生决定；错过某次活动也不阻断之后的日期。

自荐领队接入**八拍轻节奏练习**，可以用空格或轻触完成，也可以直接跳过。命中五拍以上、未达到五拍、主动跳过各有反馈和一段真实回忆；成绩不影响是否继续章节，也不用于增加羁绊。

## 3. 人物逐渐清晰

### 3.1 视觉表达

当前采用暖白纸张、鼠尾草绿、陶土红与淡彩铅笔线条。校园由 Canvas 实际绘制，封面插画只用于扉页。近景肖像使用同一四人图集，通过面部局部遮罩和清晰细节表达变化；衣服、帽子、发型、眼镜和姿态从初见就保留，方便辨认同一个人。

近景呈现为对话面板中的人物胸像，当前不包含完整的镜头推进演出。探索人物与对话、手册和回忆读取同一清晰状态。资产、图集位置和制作来源见 [美术方向](ART_DIRECTION.md)。

内部有四个阶段，界面使用自然语言而非数值等级条：

1. **陌生**：面部尚未辨清，以外部线索称呼，如“歪帽檐同学”。
2. **留意**：第一次具体经历让人物的轮廓和动作更具体。
3. **相识**：在下一天的适合地点重逢，听到介绍与顾虑，部分面容清晰，显示已知姓名。
4. **理解**：再隔一天、在新的生活情境中认识其另一面，得到完整面容。

校历事件最多让相关人物达到初步留意，不能一次跳过后续个人故事。姓名是否显示独立于视觉阶段，由实际介绍决定。

### 3.2 关系与经历

认识程度 `clarity` 与亲近程度 `trust` 分开。对教官坦白口令仍让人害怕，可以使亲近程度下降，却照常加深理解；已认识的面容不会因此重新模糊。熟悉后的日常回应会记得具体相遇与分歧。

每段个人经历使用唯一 ID，只登记一次；初见、相识和理解至少分布在三个游戏日。反复点击、进出地点、刷新或重复上报练习结果都不会生成额外关系进度。人物各自有生活日程，剧情还要满足地点、时段和前置经历；不存在靠低概率随机才能推进的必需故事。

主角一直留白。NPC 有明确背景，但其标签会被后续内容展开：跑步的人也想摄影，抱书的人也在写歌，热情的室友也有不适应，教官也曾是队列里跟不上的人。

## 4. 时间、移动与浏览器交互

标准流速为现实 1 秒对应校园 2 分钟，设置提供 2 倍与 4 倍。扉页、菜单、对话、节拍练习、页面隐藏及结局期间暂停计时；离线不补算时间。普通个人对话不额外扣分钟；校历活动的选择先停留在反应页，关闭后再推进到该活动结束时刻。

「等一会儿」一次最多推进三十分钟，并停在更近的人物日程边界、活动提醒、开始或结束时刻。19:00 后在宿舍附近可以休息至次日 07:00。每天 22:00 停止推进，等待玩家回宿舍；第五日 22:00 自动进入回忆，结营后也可提前回宿舍合上这一章。

地图支持 WASD／方向键移动、点击或轻触目的地、点击人物或地点后走近互动；建筑与池塘参与碰撞和寻路。鼠标拖动／触控拖动平移地图，滚轮或按钮缩放，也可回到玩家位置。按 E／空格就近互动，数字 1—4 选择，Esc 暂停或返回。

NPC 目前按时段直接切换活动点，日程集合覆盖日常安排；没有连续行走的自主 NPC 系统。响应式布局面向桌面和移动视口，实际设备触控与性能仍需持续验证。音效为 Web Audio 合成脚步、轻响与训练节拍，没有完整配乐或配音。

## 5. 存档与章末回忆

使用当前浏览器 localStorage 保存日期、时间、位置、日程、关系、剧情标记、实际经历与当前对话。无需登录，没有云同步。选择前读档恢复选项，选择后读档恢复反应页，已登记的经历不再应用一次。界面提供自动存档、继续生活和带确认的新一局；旧版 Ink 存档不迁移。

选择领队自荐后尚未完成练习即关闭页面，继续时会重新开始这次短练习；已完成或已跳过的练习保存事实，不重复计分。清理浏览器数据会清除进度，存储受限时只保证当前页面内可继续操作。

章末展示人物当前认识状态，以及本局真实发生的代表性片段；所有记忆可在手册查看，并导出 UTF-8 文本。缺席或安静选择不被写成人格失败，也不会揭示没有经历的秘密。完全没有故事记忆的路径保留“你走过的校园”，人物仍保持陌生。

## 6. 工程、验收与边界

新工程采用原生 ES 模块、Canvas 2D、CSS、Web Audio 和 localStorage，不依赖前端框架或 Ink。`src/content.mjs`、`simulation.mjs`、`world.mjs`、`main.mjs` 分别承担内容、模拟状态、地图导航、浏览器交互；同一状态驱动日程、人物、存档与回忆。

Node.js 22 或更新版本下，开发流程为：

```bash
npm ci --omit=optional
npm run dev
npm test
npm run build
```

开发服务器默认 `127.0.0.1:3000`，支持 `npm run dev -- --port 3001`。构建只产出 `dist/`，保留原生模块和资源路径；手动部署与 CI 都上传同一完整目录，Nginx 提供 `.mjs` JavaScript MIME 与 `no-cache`。账号和目标站点保持原配置，本轮未运行远端部署，详见 [部署文档](../DEPLOY.md)。

旧运行工程、Ink 编译链、对齐工具和过时初始化脚本已经移除。POC、assets 原始参考和旧设计文档继续保留，其历史路径与旧规则不作为新运行方式。`githooks/pre-commit` 只执行 `npm test`，不会修改或暂存文件。

逻辑、地图和服务器测试已经分别执行。最终全套检查及桌面／移动浏览器回归正在整合，实际状态以 [HANDOFF.md](../HANDOFF.md) 为准；不把“已实现”写成“已发布”或“所有设备已验证”。

后续学期、期中考试、社团招新、跨章节关系延续、多主角匹配、订阅、云存档、多人联网、自动分享与埋点均不在本次范围。此版用于完整验证军训篇的探索—相遇—选择—逐渐理解—回忆循环，不承诺覆盖大学四年或固定总游玩分钟数。
